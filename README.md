# Domain Guard - 偽ドメイン検知

フィッシング詐欺でよく使われる**偽ドメイン（なりすましURL）**を、閲覧中のページに対してリアルタイムに解析し、危険度を警告する Chrome 拡張機能です。

## 検出できる攻撃パターン

| ルール | 例 |
|---|---|
| タイポスクワティング | `gooogle.com` `g00gle.com` `paypa1.com` |
| 同形異義語攻撃（punycode） | キリル文字の「о」を混ぜた `gоogle.com` |
| 正規ドメインの埋め込み | `paypal.com.evil-example.com` `www.google.co.jp.fake-site.net` |
| ブランド名の無断使用 | `secure-paypal-login.top` |
| URL内「@」偽装 | `https://google.com@evil-phish.com/` |
| IPアドレス直指定 | `http://192.168.10.5/login.php` |
| 高リスクTLD | `.tk` `.ml` `.zip` `.mov` `.top` `.xyz` など |
| 誘導キーワード | login / verify / update / 確認 などを含むドメイン |
| 無料ホスティング | `*.herokuapp.com` `*.vercel.app` など |
| 短縮URL | `bit.ly` `t.co` など |
| HTTP通信 | 暗号化されていない通信（特にログイン関連） |
| Google Safe Browsing（任意） | 既知のフィッシング・マルウェアURL |

判定は加点方式で、合計スコア（0〜100）から危険度を算出します。

- **安全**（緑） — 問題なし
- **ほぼ安全**（黄） — 軽微な兆候
- **要注意**（橙） — 確認を推奨
- **危険の可能性大**（赤） — 個人情報の入力前に必ず確認
- **危険**（赤・濃色） — アクセス警告（ブロック設定時）

## インストール方法（開発者モード）

1. Chrome で `chrome://extensions` を開く
2. 右上の「**デベロッパーモード**」を ON にする
3. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
4. この `domain-guard` フォルダを選択

## 使い方

- **自動判定**: http/https のページを開くと自動解析され、ツールバーのアイコンに バッジ（`OK` `!` `!!` `!!!` `危`）が表示されます
- **詳細を見る**: アイコンをクリックすると、検出された問題の一覧と解説が表示されます
- **誤検知を除く**: ポップアップの「`『example.co.jp』を信頼済みに追加`」ボタン、または設定画面のホワイトリストに登録
- **再解析**: ポップアップの「再解析」ボタン（キャッシュを無視して再チェック）

## 設定画面（オプション）

ツールバーのアイコン → ⚙、または `chrome://extensions` → Domain Guard → 「拡張機能のオプション」

| 設定 | 説明 |
|---|---|
| 検知機能の有効/無効 | 全体の ON/OFF |
| 検知の感度 | 緩い / 標準 / 厳しい（スコア係数 0.6 / 1.0 / 1.4） |
| 危険なサイトのブロック | 「危険」と判定したサイトを開こうとしたとき、専用の警告ページに切り替える |
| デスクトップ通知 | 危険検知時に OS 通知を表示 |
| Safe Browsing API | Google のデータベースと照合（APIキーは任意） |
| ホワイトリスト | 信頼するドメインの追加・削除 |

### Safe Browsing APIキーの取得（任意）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「Safe Browsing API」を有効化し、APIキーを発行
3. 設定画面でキーを入力し「APIキーをテスト」→ 有効なら自動で連携が ON になります

無料枠内で個人利用には十分です。キー未設定でも、上記ヒューリスティック解析はすべて動作します。

## ディレクトリ構成

```
domain-guard/
├── manifest.json          # Manifest V3 定義
├── background.js          # Service Worker（解析実行・バッジ・ブロック・通知）
├── lib/
│   ├── analyzer.js        # コア解析エンジン（スコアリング）
│   ├── brands.js          # 正規ブランドドメイン・キーワードDB
│   ├── punycode.js        # punycode デコーダー
│   └── utils.js           # レーベンシュタイン距離・TLD解析・文字種解析
├── popup/                 # 判定ポップアップUI
├── options/               # 設定画面
├── warning/               # 危険サイトアクセス時の警告ページ
├── icons/                 # アイコン（16/32/48/128）
├── _locales/              # ja / en メッセージ
└── tools/
    ├── generate_icons.py  # アイコン再生成スクリプト（PIL不要）
    └── test_analyzer.mjs  # 解析エンジンの回帰テスト
```

## テスト

```bash
node tools/test_analyzer.mjs
```

正規サイトが安全判定になり、代表的なフィッシングパターンが検出されることを確認します。

## 注意事項

- 判定は**ヒューリスティック解析による参考情報**であり、100%正確ではありません。正規サイトが警告される（誤検知）・新しい手口を見逃す（見逃し検知）可能性があります
- ホワイトリストへの登録は慎重に行ってください。登録したドメインは一切警告されなくなります
- パスワード・クレジットカード・マイナンバーなどの入力前に、必ずアドレスバーのドメインをご確認ください
- 本拡張機能は通信内容を収集・送信することはありません（Safe Browsing API 使用時のみ、閲覧URLを Google に送信します）
